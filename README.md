# Inventta Computador — Atualizações

Canal oficial de downloads e atualizações do **Inventta Computador**, o organizador de inventário florestal da SC Topografia.

## Baixar

O instalador de cada versão fica em [Releases](https://github.com/sc-topografia/inventta-atualizacoes/releases/latest): arquivo `Inventta-Computador-Setup-X.Y.Z.exe`.

- Instala para o usuário do Windows, sem pedir administrador.
- Depois de instalado, o programa procura versões novas sozinho ao abrir, baixa em segundo plano, confere o arquivo e instala quando você escolher ou ao fechar.
- Antes de cada atualização o programa guarda uma cópia de segurança dos dados.
- Se o Windows avisar "editor desconhecido" ao abrir o instalador: **Mais informações → Executar assim mesmo**.

## Sobre este repositório

Este espaço guarda só os arquivos de distribuição (instaladores e o arquivo `versao.json` que o programa consulta). O código-fonte do programa é privado e nenhum dado dos usuários fica aqui.
